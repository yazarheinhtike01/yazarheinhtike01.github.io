          How to use the agent

          Tasks

          Add tasks, then refer to them by the number shown in the Tasks panel.

          add task Finish the report add task Call the dentist at 15:30 done 1 delete task 2

          Reminders & notes

          Set reminders with a time (add “tomorrow” for the next day) and save quick notes.

          remind me at 08:00 to take medicine remind me tomorrow at 09:30 to leave for the station note Wi-Fi password is on the router delete reminder 1

          Expenses & overview

          Record spending in yen and ask the agent to show any list at any time.

          spent 420 on train expense 1200 groceries show expenses what can you do
